## Scope And Counts / 范围与计数

The audit inventories top-level entries in the three exported roots, deduplicates GitHub repositories in explicit SOURCE.md/PROVENANCE.json records, and retrieves current default HEAD using `git ls-remote`. It does not infer original provenance from arbitrary links in a Skill body. Nested open-design packs, `.system` and installed/bundled plugins are not version-audited. The manifest lists 818 entrypoint files including nested entries and duplicate export copies; it is not a count of independent capabilities.

HEAD drift may affect only README/runtime files, not the Skill. Missing provenance is not evidence of obsolescence, and should not trigger destructive replacement.
