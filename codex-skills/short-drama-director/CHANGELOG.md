## 2026-08-28 · V6.0（发布前修订）

> 本次为「漫剧老李 AIGC 全流程 Skill」正式定名 V6.0。

本次修订为发布前的一次系统性规则审计与修复，主要目标：修复内容错误、统一规则口径、提升平台合规可靠性，并补齐 GitHub 发布文件。

### 🔧 修复（Bug Fixes）

- **箭头/换行编码损坏**：修复 `SKILL.md`、`action-previs-15grid.md`、`combat-direction-engine.md`、`martial-arts-combat-library.md`、`action-ultimate-finisher.md`、`anime-ultimate-vfx-paradigm.md` 中损坏的 `\rightarrow`（含 CR 字节污染）。
- **台词语速自检模块（dialogue-speed-check）**：
  - 修正“最短/最长时长”上下限命名颠倒；
  - 字数口径改为只数可发音字符，标点另计停顿预算；
  - 修正示例字数：原台词实际 33 字（原写 30），拆镜三句为 16/7/11 字（原写 19/8/14）；
  - 语速自检卡改为内部 QC 附件，不写入最终提示词正文。
- **平台合规模块**：删除“100% 安全合规 / 畅通渲染”虚假承诺，改为“降低风险、以平台实时政策为准”；新增三级输出模式（安全默认 / 强动作非血腥 / 成人级创作草案）。
- **时长体系统一**：修正 100 秒/180 秒矛盾——三幕结构改为按目标时长百分比换算；单组时长 ≤15 秒、1~4 镜不强制；180 秒折合 14~15 组。
- **血腥/要害词温和化**：清洗 `authentic-martial-taxonomy`、`martial-arts-combat-library`、`action-previs-15grid` 等文件的“爆头 / 颈动脉 / 断子绝孙 / 血沫 / 骨碎 / 穿心 / 刺喉”等表达，保留技术性招式名，去致命化。

### ✨ 优化（Improvements）

- **动作强度三档（R1/R2/R3）**：新增写实克制 / 商业高燃（默认）/ 玄幻大招三档，将“开局硬撞、肘击必含、11 环全展开、气爆必出、重创定格”等硬规则限定到 R2/R3。
- **完播率公式 → 完播潜力评分**：乘法公式改为加权启发式评分（0.20/0.30/0.25/0.25），并注明非平台预测模型。
- **资产 A/B/C 分级**：主角 16 项、常驻配角 8 项、群众 3~5 项，避免资产膨胀。
- **合法越轴**：新增中性镜头过渡、轨道可见越轴、角色换位、特写重置轴线等合法方式。
- **9:16 竖屏完整模板**：补全竖屏模板（安全区、人物占屏比、高低位构图、纵向接续）。
- **声音电平**：改为相对增益表述（对白 0 / SFX -6 / BGM -14~-18），落地成片以平台响度标准为准。
- **导演/IP 去重**：芬奇/斯皮尔伯格/黑泽明法则 → 技术化命名；独孤九剑→破招剑术、梦想一心→雷元素太刀、死神镰刀→长柄镰刀。
- **UE5/8K 去强制**：画质声明改为可选预设（3D 写实 / 2D 动画）；符文改不可读抽象符纹防乱码。
- **日景冷光**：允许有环境依据的自然冷色（阴天/雪地/雨日），仅禁无来源棚拍假冷光。
- **美学预设补全六维**：每种风格补齐“快门运镜”维度。
- **剧本门控柔性化**：黄金钩子新增关系钩/喜剧钩/信息缺口钩；cliffhanger 允许完结算集不挂钩；日常/治愈题材允许关系闲聊。

### ➕ 新增（New）

- `references/model-adapters.md`：多平台参数适配层（Seedance/即梦/可灵/MiniMax H3）+ 投喂前清单 + 失败降级策略 + 输入/输出契约。
- `scripts/check_package.py`：静态自检脚本（CR/箭头/模块数量/时间轴/危险词/IP 词）。
- `README.md`、`LICENSE`（MIT）、`CHANGELOG.md`。

### 结构变更

- `SKILL.md` 模块数量统一为 23；质量门禁正式并入语速维度。
