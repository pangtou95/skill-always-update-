# AI Agent Book Guide

Use [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book) as a learning map, not as an automatically installed application.

## Route The Request

| Need | Chapter |
| --- | --- |
| Agent foundations and harnesses | 1 |
| Context engineering and Skills | 2 |
| Memory, RAG, indexes, knowledge graphs | 3 |
| Tools, MCP, discovery, event-driven agents | 4 |
| Coding agents and code generation | 5 |
| Evaluation and statistical comparison | 6 |
| SFT, RL, and tool-use post-training | 7 |
| Learning from traces and continual improvement | 8 |
| Voice, computer use, robotics | 9 |
| Multi-agent collaboration | 10 |

## Workflow

1. Confirm the target outcome and current level from available context.
2. Open the current upstream chapter and relevant experiment README. Prefer the inspected commit in `references/source.md` for reproducibility; check upstream when freshness matters.
3. Separate conceptual reading from runnable experiments. Inspect each experiment's own dependencies, hardware, credentials, and license before execution.
4. Produce a short learning path with checkpoints and one practical artifact per stage.
5. Verify claims against the chapter text and primary references. Do not repeat sponsor claims as technical recommendations.

Never claim an experiment ran merely because its repository cloned or dependencies installed.

Read `references/source.md` for source version and license.
