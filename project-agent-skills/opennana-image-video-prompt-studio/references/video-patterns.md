# Video Pattern Library

## Control Grammar

Use this sequence:

`hook -> subject/action chain -> blocking -> camera -> transition -> light/material -> audio -> payoff -> locks`

## Family Controls

| Family | Beat logic | Critical checks |
| --- | --- | --- |
| Dance/performance | entrance, signature move, escalation, held ending pose | full-body framing, rhythm, limbs, wardrobe continuity |
| Creator/UGC | immediate hook, demonstration, reaction/proof, CTA | natural eyeline, product legibility, credible speech |
| Product selling | problem, feature action, proof, price/offer, hero close | exact claims, label geometry, no invented endorsement |
| Comedy/dialogue | setup, expectation, interruption, reversal, reaction | speaker map, timing pause, lip sync, readable geography |
| Cinematic encounter | environmental setup, eyeline, approach, emotional turn | screen direction, identity, motivated camera movement |
| Beat-sync transformation | stable anchor, music accents, staged changes, clean reveal | subject position, transition causality, no uncontrolled morphing |
| Action/martial arts | threat, readable attack, contact/deflection, aftermath | safe choreography, spatial axis, physics, no duplicated weapons |
| Food/craft | ingredients/tools, ordered action, sensory close-up, finished proof | hand/tool contact, process order, food safety, continuity |
| Fantasy/anime/game | world rule, ability setup, clash, consequence | character locks, readable effects, world-scale consistency |
| Immersive tour | entry, route landmarks, reveal, exit/endpoint | camera path, no teleportation, environmental continuity |
| Automotive/brand | design detail, ignition/motion, performance proof, hero frame | authorized marks, vehicle geometry, legal/safe behavior |
| Existing-video edit | source state, timestamp changes, preserved lanes, new endpoint | no edits outside scope, audio sync, frame continuity |

## Beat Rules

- 4-8 seconds: one or two beats.
- 9-15 seconds: two or three beats.
- 16-30 seconds: three to six beats.
- Each beat gets one purpose, one main action, one camera instruction, one audio cue, and one endpoint.
- Dialogue needs named speakers, language, exact line, emotional delivery, and time window.
- End on a stable visual state long enough for evaluation or CTA use.

## Failure-Driven Negatives

Use only likely failures: identity swap, extra subject, malformed contact, prop mutation, unreadable product text, camera-axis reversal, unmotivated cut, lip-sync drift, speaker swap, subtitle invention, looping action, or changed final frame.
